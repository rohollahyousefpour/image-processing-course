# Week 6 Deliverable — The Frequency Domain
# تحویلیِ هفتهٔ ۶ — حوزهٔ فرکانس

**Due:** before Week 7. **Weight:** part of the 25% weekly grade.

## Tasks (real images from `E:/data`)
1. **Spectra.** Compute and display the log-magnitude spectrum of 3 images (a plate, a
   textured image, a smooth one). Interpret each: where is the energy, any dominant directions?
2. **Low/high-pass.** Filter by masking the spectrum; compare the results to spatial
   blur/edges (Weeks 3, 5). Note the effect of an ideal (hard) vs Gaussian (soft) cutoff.
3. **Periodic noise.** Add stripe noise; locate the peaks in the spectrum; remove them with a
   notch filter (`../code/notch.py`). Show before/after.
4. **Note.** For DocScan, when is frequency-domain the right tool (e.g. a patterned scan), and
   when is spatial simpler?
